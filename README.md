## 配置够不够用？人数、模组和带宽的实际门槛

10 人套餐对大多数朋友服够用；常驻人数接近 15 人，或者要装大型模组包，直接上 20 人档更稳。

判断配置可以看三个维度：

1. **同时在线人数**：服务器能带多少人主要看带宽。1–10 人的小服，3–8M 带宽就能跑；10–30 人建议 10M 起；30 人以上要 30M 起。腾讯云套餐按 10 人/20 人卖，省去自己算带宽的步骤。
2. **模组和插件**：原版生存要求不高，双核 2.5GHz、4GB 内存就能起步；装了 Forge 模组包之后，内存和 CPU 占用会明显上升，10–30 人档一般建议 4 核 3.0GHz、8GB 内存起。
3. **操作系统**：走自建路线优先 Linux（Ubuntu）。用 Windows 跑 MC 服务端会明显拖性能，一两个人上线就可能卡。

这也是开箱即用套餐省心的地方：硬件和带宽按人数配好，不用逐项核对 CPU 主频和内存。真正需要你决定的只有两件事：人数峰值和模组规模。
